# 📊 Excel Sales Dashboard Project

## Project Overview

This project is an **Interactive Sales Dashboard built in Microsoft Excel**.
The dashboard is designed to analyze sales performance, track target achievement, compare sales executives, and provide clear business insights using Excel features.

This project helped me understand how raw sales data can be transformed into a clean, interactive, and meaningful dashboard for better decision-making.

---

## Objective

The main objective of this project is to create a user-friendly Excel dashboard that helps managers quickly understand:

* Total sales performance
* Sales executive-wise performance
* Target hit percentage
* Away-from-target percentage
* City-wise sales analysis
* Performance comparison using charts and slicers

---

## Tools & Technologies Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Dashboard Styling
* Macros
* VBA Automation

---

## Key Features

* Interactive city-wise slicers
* Dynamic dashboard view
* Sales executive-wise total sales analysis
* Target hit percentage analysis
* Away-from-target percentage analysis
* Pivot charts for visual comparison
* Clean and professional dashboard layout
* VBA and macros used for automation

---

## Dashboard Preview

![Dashboard Preview](Dashboard_Screenshot.png)

---

## Dataset Description

The dataset contains sales-related information such as:

* Sales Executive Name
* City
* Total Sales
* Target Hit Percentage
* Away From Target Percentage

This data was used to create pivot tables, charts, and slicers for interactive analysis.

---

## Business Questions Answered

This dashboard helps answer important business questions such as:

1. Which sales executive achieved the highest sales?
2. Which sales executive is away from the target?
3. What is the target hit percentage of each executive?
4. How does performance vary city-wise?
5. Which employees need improvement?
6. Who are the top-performing sales executives?

---

## Business Insights

* The dashboard helps identify top-performing sales executives.
* It highlights employees who are away from their targets.
* City-wise slicers make it easy to analyze sales performance by location.
* Pivot charts make the data easier to understand visually.
* Managers can use this dashboard to take quick decisions and improve sales performance.

## How to Use This Project

1. Download the Excel file from this repository.
2. Open the workbook in Microsoft Excel.
3. Enable macros if prompted.
4. Use slicers to filter data city-wise.
5. Explore charts and tables to analyze sales performance.

---

## Important Note

This workbook contains **VBA macros**.
Please enable macros to use all automation features properly.
